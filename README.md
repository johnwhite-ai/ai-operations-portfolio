## Projects

### 1 · Agent Operations Framework
**A multi-agent system organized like a company — that extends and improves itself.**

An orchestrator coordinates five specialist departments (twelve agents). Every output is tagged Confirmed / Estimated / Missing. When the system hits a capability it lacks, the **Capability Gap Protocol** scouts, adapts, or builds a new agent and keeps it.

`Claude` · `multi-agent orchestration` · `self-extending architecture`
→ **[Open project](01-agent-operations-framework/)** · [SHOWCASE](01-agent-operations-framework/SHOWCASE.pdf)

### 2 · CS2 Analytics Engine&nbsp;&nbsp;`Live`
**Raw game data in. A coached, actionable performance report out. Fully automated.**

An end-to-end Python pipeline that parses raw replay files, computes metrics across five analytical dimensions, and generates a sourced report with prioritized recommendations.

`Python` · `data pipeline` · `FastAPI` · `dashboard`
→ **[Open project](02-cs2-analytics-engine/)** · [SHOWCASE](02-cs2-analytics-engine/SHOWCASE.pdf)

### 3 · AI Career Operations System&nbsp;&nbsp;`Live`
**An agentic system that runs a real job search: scan, score, research, draft.**

Scans target companies across ATS boards, Indeed, a European pass, and LinkedIn alerts; hard-filters non-starters; scores every role against a personal North Star rubric; produces a ranked daily report and syncs to Notion. It is running the search behind this portfolio.

`Claude` · `agentic workflow` · `Notion + Gmail integration`
→ **[Open project](03-ai-career-operations-system/)** · [SHOWCASE](03-ai-career-operations-system/SHOWCASE.pdf)

### 4 · Autonomous Planning System
**Scheduled cloud agents that plan your week and verify what you actually did.**

Two cron agents read context across five tools, draft a plan where every action is a checkbox, and wait for one-click approval. The standout feature: it verifies yesterday's work against real evidence (commits, sent messages, file edits) rather than memory.

`Claude` · `cloud cron` · `multi-source reconciliation` · `human-in-the-loop`
→ **[Open project](04-autonomous-planning-system/)** · [SHOWCASE](04-autonomous-planning-system/SHOWCASE.pdf)

### 5 · ops-profiler
**Raw, messy operational data in. A structured, fully sourced profile out.**

Ingests inconsistent customer data (CSV, XLSX, prose) and produces a profile where every value is tagged Confirmed / Estimated / Missing and traced to its exact source. Deterministic core with AI only at the checked edges, so the output is defensible enough to price a multi-million-dollar system on. Cut profiling from half a day to two minutes.

`Python` · `deterministic core + checked AI edges` · `provenance tracking`
→ **[Open project](05-ops-profiler/)** · [SHOWCASE](05-ops-profiler/SHOWCASE.pdf)

## About

I am an AI operations and process optimization professional with 8 years in industrial engineering, process optimization, and AI-enabled systems design. I do not start from the tool. I start from where the work actually breaks, then build the workflow or agent that fixes it and gets adopted.

That instinct shows up across this portfolio: when AI hits a wall, I redesign the system around the wall rather than abandoning it. The Agent Operations Framework's self-extending design came from exactly that — agents that kept breaking as products and customers changed, rebuilt into a system that acquires what it lacks.

**Background:** Industrial & Management Systems Engineering (WVU) · 8 years across logistics, robotics, and manufacturing · $600K+ documented operational impact · Lean Six Sigma Green Belt.
